# AI Outfit Generator

## Project Overview
This project is an AI-powered Outfit Generator built using Flask. It receives wardrobe items, occasion, and season from the frontend, generates an AI prompt, and prepares it for AI model integration.

## Technologies
- Python 3.9.6
- Flask
- Postman
- Git & GitHub
